# `Problem: What are you trying to predict?`
This lab aims to predict the Net Electrical Power Output of a power plant based
on four input variables.
```
# `Dataset: What are the inputs and target?`
The input variables are Ambient Temperature, Exhaust Vacuum, Ambient Pressure,
and Relative Humidity. The target variable is the Net Electrical Power Output.
```
# `Models: Which two models did you compare?`
This lab compared a Linear Regression Model with a Shallow Neural Network.
```
Evaluation: Which metrics did you use?
The lab uses three metrics to evaluate the performance of both models: Mean
Absolute Error (MAE), Root Mean Squared Error (RMSE), and Coefficient of
Determination (R^2)
```

```
Main Result: Which model performed better?
```

```
After tuning, the Shallow Neural Network performed slightly better in all
metrics.
```
